# bank247-txn-frontend

Bank247 transaction-processing staff UI (Vite + React + TypeScript).

## Current screens

- Staff login (Log-In 34 + Log-In 32 brand panel) → `/login`
- Accounts hub (Figma `ACCOUNT/CUSTOMER` + `INTERNAL`) → `/accounts`
- Add New Account modal (Figma `ACCOUNT/Add New.png`)

Design refs: `design-reference/ACCOUNT/`.
